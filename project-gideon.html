GIDEON — Smart Offline AI Voice Assistant

A compact, privacy-preserving offline AI voice assistant built on Raspberry Pi 5. Combines on-device Whisper speech recognition, a local TinyLlama LLM served via llamafile, and eSpeak-NG speech synthesis for real-time natural interaction without cloud or internet dependency.

Project Overview

Conventional voice assistants such as Siri, Alexa, and Google Assistant require constant internet connectivity and upload user audio to third-party cloud servers. This introduces data privacy risks, recurring latency, and complete failure in internet-denied environments.

GIDEON addresses this by running the entire artificial intelligence pipeline directly on edge hardware. Built on a Raspberry Pi 5, it captures spoken queries, transcribes them locally using OpenAI's Whisper model, feeds the text into an on-device TinyLlama large language model hosted through a llamafile server, and converts the generated response into speech via eSpeak-NG — all with zero internet connection.

How GIDEON Operates

The system operates in three tightly integrated processing stages:

1. Voice Capture & Speech-to-Text

User speech is captured via a USB microphone and digitized using ALSA audio drivers. The audio is transcribed locally by the OpenAI Whisper model into high-accuracy text.

2. Local LLM Reasoning

The transcribed prompt is sent to a locally hosted TinyLlama LLM served through a llamafile server, generating intelligent, context-aware answers without any external API calls.

3. Speech Synthesis & Audio Output

The generated response text is synthesized into natural audio using the eSpeak-NG text-to-speech engine and broadcast through an attached Bluetooth speaker.

Key Advantages

  • 100% Privacy-Preserving: No audio or transcripts ever leave the device.
  • Zero Cloud Dependence: Operates reliably without WiFi or cellular network access.
  • Low-Cost Edge Hardware: Implemented on standard Raspberry Pi 5 hardware.
  • Expandable Architecture: Ready for integration with smart home automation, offline education, and accessibility tools.
