## 🚀 Featured Projects

1. **[Autonomous Service & Hospitality Robot](project-robotics.html)**
   - Human-scale service robot featuring custom welded steel chassis, composite outer body casing, digital animated facial expression display, and payload delivery tray.
2. **[FireTrack — Hybrid Indoor Firefighter Localization & Health Monitor](project-firetrack.html)**
   - Safety-critical wearable system combining boot-mounted IMU dead reckoning, RFID anchor correction via Kalman filter fusion, and live WiFi telemetry dashboard on VEGA RISC-V processor.
3. **[Smart Wireless Automated Irrigation System](project-irrigation.html)**
   - Precision agriculture system automating irrigation through real-time soil moisture, NPK sensors, temperature/humidity monitoring, and relay-driven water pump control.
4. **AI CCTV Attendance System (Christ Silicon AI)**
   - Computer vision facial recognition system leveraging existing CCTV infrastructure for automated scalable attendance tracking.
5. **Human-Sized 3D Body Scanner**
   - Automated optical body measurement system developed to eliminate tailoring measurement errors.
6. **Autonomous Black Soldier Fly Organic Recycler**
   - Sustainable automated organic waste recycling system converting organic matter into bio-compost and protein feed.
